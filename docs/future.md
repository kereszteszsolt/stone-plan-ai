# Future ideas (not a roadmap)

These are **ideas only**, with no assigned release, stories, or acceptance criteria.

- **AI replanning:** Redistribute unfinished subtasks across the remaining days.
- **Calendar export:** Download accepted plans as `.ics` files.
- **Google Calendar integration:** Create calendar events directly after user authorization.
- **AI tool calling:** Let the AI read existing tasks or suggest calendar actions through controlled tools.
- **Project grouping (later):** Organize related tasks into projects.
- **Multi-user support (later):** Add accounts, JWT authentication, and NestJS Guards to separate users' data.

None of these is planned for implementation now. The Release 0.1 scope does not depend on any of these ideas.
